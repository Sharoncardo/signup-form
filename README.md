# A Signup Form That Doesn't Suck

## 🚀 Live Demo
https://signup-form-mutl.onrender.com/

---

## 📌 Project Description
A polished multi-step signup form with validation, draft saving, and secure backend validation.

---

## ✨ Features
- Multi-step signup form (Step 1 & Step 2)
- Client-side validation (instant feedback)
- Server-side validation (secure, cannot bypass)
- Draft saving using localStorage
- Form state preserved on refresh
- Accessible error messages
- Disabled submit while loading
- Success message on completion

---

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- Node.js
- Express.js
- localStorage

---

## ⚙️ Validation Rules
- Name: Minimum 3 characters
- Email: Must contain "@"
- Password: Minimum 6 characters
- Age: Must be 18 or above
